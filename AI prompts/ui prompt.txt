# 8. PAGE-SPECIFIC DESIGN

مهم‌ترین قانون:

## طراحی صفحه باید بر اساس PAGE NAME انجام شود.

نام صفحه را تحلیل کن و خودت تشخیص بده:

* چه نوع صفحه‌ای است؟
* هدف کاربر چیست؟
* چه محتوایی باید نمایش داده شود؟
* چه Sectionهایی مناسب آن هستند؟
* چه CTAهایی لازم است؟
* چه نوع Cardهایی مناسب هستند؟
* چه اطلاعاتی باید در Above The Fold قرار بگیرد؟
* چه اطلاعاتی برای SEO و UX مفید هستند؟

مثلاً:

اگر صفحه:

Home

بود، یک Homepage کامل و فروشگاهی طراحی کن.

اگر:

Shop

بود، یک Product Listing Page حرفه‌ای طراحی کن.

اگر:

Product

بود، یک Single Product Page کامل با Gallery، اطلاعات محصول، قیمت، Variant، CTA، توضیحات، مشخصات و محصولات مرتبط طراحی کن.

اگر:

Blog

بود، یک Blog Archive حرفه‌ای طراحی کن.

اگر:

About

بود، صفحه معرفی برند را به‌صورت Editorial + Brand Story طراحی کن.

اگر:

Contact

بود، صفحه تماس با فرم و اطلاعات تماس و ساختار اعتمادساز طراحی کن.

اما این‌ها فقط مثال هستند.

**برای هر Page Name خودت بهترین ساختار UX/UI همان صفحه را طراحی کن.**
